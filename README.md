# Vibe Remote — Release Distribution

This repository hosts release binaries for the [Vibe Remote](https://vibe-remote.com) CLI.

**Source code and development:** [btelo-platform/vibe-remote-dev](https://github.com/btelo-platform/vibe-remote-dev)

**Latest canonical release location (since 2026-04-17):** [btelo-platform/vibe-remote-release](https://github.com/btelo-platform/vibe-remote-release)

This legacy mirror exists to keep older installed CLIs working during the
transition period. Please install the latest CLI via:

```bash
curl -fsSL https://vibe-remote.com/install.sh | sh
```
